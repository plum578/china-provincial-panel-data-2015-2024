# China Provincial Panel Data (2015–2024)
This repository contains the provincial-level panel dataset used for the empirical analysis in our study.

## Data Source
All variables are extracted from *China Statistical Yearbook* (National Bureau of Statistics of China).

## Files
- `china_provincial_panel_2015_2024.xlsx`: Cleaned panel dataset (31 provinces, 2015–2024, 19 variables).
- Variable list and units are specified in column headers.
